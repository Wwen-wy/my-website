# Aurora · 以 AI 疗愈 AI 焦虑

INT6140《工作与人力的未来趋势》个人数字化反思作品集（香港教育大学 GIET）。

**核心命题**：既然 AI 替代焦虑由 AI 引发，疗愈它最有力的工具，恰恰也是 AI。

## 页面

| 路径 | 内容 |
|---|---|
| `index.html` | ePortfolio 主站（四大模块：职业画像 / 科技剖析 / 福祉设计 / 反思路线） |
| `aurora.html` | Aurora 交互系统：6 轮对话测评 → 风险报告 → 能力画像 → 情绪疏导 |
| `print.html` | A4 打印归档版（浏览器打开后 Ctrl+P 可导出 PDF，需勾选"背景图形"） |
| `assets/` | 业务流程图 SVG、能力画像海报 |

## 技术说明

- 纯静态页面，无构建步骤、无后端依赖，可直接部署到 GitHub Pages
- 交互测评使用前端关键词情绪识别引擎（焦虑词/倦怠词加权打分），结果随输入动态生成
- 字体走 Google Fonts（思源宋体 + Inter），离线时回退系统字体

## 生成式 AI 使用声明

页面中的海报图像、流程图、交互代码由生成式 AI 辅助完成；核心观点、个人经历与反思内容由作者本人撰写并对其真实性负责。详见主站附录 A。
